# 악보 넘김 (ScoreTurner)

아이패드 사파리에서 쓰는 PDF 악보 보기 웹앱입니다. 설치나 서명 없이 **홈 화면에 추가**해서 앱처럼 씁니다.

## 기능
- **악보 서재**
  - 파일 앱에서 PDF를 한 번 가져오면 기기 안에 남습니다. 여러 개를 한 번에 가져올 수 있습니다.
  - 최근 연 악보와 전체 목록, 이름 찾기
  - 마지막으로 본 쪽을 기억합니다.
- **악보 보기**
  - 세로는 한 쪽, 가로는 두 쪽으로 보여 줍니다.
  - 화면 왼쪽·오른쪽 누르기, 좌우로 밀기, 블루투스 넘김 페달(화살표·PageDown·스페이스)로 넘깁니다.
  - 보는 동안 화면이 꺼지지 않습니다.
- **메트로놈**
  - 악보 PDF의 템포 표시(예: ♩=90, Andante)를 읽어 추천 BPM을 미리 넣어 둡니다.
  - 숫자를 직접 입력할 수 있고, 악보마다 마지막 값을 기억합니다.
- **메모 (애플 펜슬)**
  - 검정·빨강·파랑 펜, 형광펜, 지우개, 되돌리기
  - 쪽마다 저장됩니다.
  - 메모 중에는 손바닥이 닿아도 쪽이 넘어가지 않습니다.
- **자동 넘김 (마이크)**
  - 마이크로 연주를 듣고 지금 치는 줄을 따라가다가, 마지막 줄 중간쯤에서 다음 쪽으로 넘깁니다.
  - 악보를 처음 열 때 한 번 대략 읽어 두고(쪽 넘기기용 음 순서만), 기기 안에 저장합니다.
  - 틀려서 몇 마디 앞에서 다시 치면 따라 돌아갑니다. 손으로 넘기면 그 쪽 처음부터 다시 따라갑니다.
  - 한 번 켜 두면 악보를 열 때마다 저절로 듣고, 서재로 나가거나 다른 앱으로 가면 마이크를 끕니다.
- **처음 사용 안내**: 홈 화면 추가, PDF 가져오기, 넘기기, 자동 넘김, 메트로놈, 메모를 화면 위에서 하나씩 짚어 알려 줍니다. `?` 버튼으로 다시 볼 수 있습니다.
- **오프라인**: 처음 한 번 열면 인터넷 없이도 열립니다.

## 자동 넘김의 구조
- `js/omr.js`: 쪽 넘기기용 대략 악보 인식. 오선, 음표 머리, 음자리표, 조표, 임시표를 찾습니다.
- `js/listen.js`: 마이크 소리 → 새로 친 음이 생기는 순간마다 12음 분포(크로마).
- `js/follow.js`: 악보 사건과 들은 소리를 확률 모형(은닉 마르코프 모형)으로 맞춰 위치를 정하고, 넘길 쪽을 판단합니다.
- 아직 실제 피아노(업라이트) 소리로는 충분히 시험하지 않았습니다. 가상 녹음으로 맞춘 값입니다.

## 개인 정보·저작권
- 악보 PDF, 메모, 인식 결과는 **이 기기의 브라우저 저장소에만** 있습니다. 서버로 보내지 않고, 분석 도구도 쓰지 않습니다.
- 마이크 소리는 이 기기 안에서 음 분포만 계산하고, 녹음하거나 어디로 보내지 않습니다.
- 이 저장소에는 앱 코드만 있습니다. 악보 파일은 들어 있지 않습니다.
- 악보는 사용자가 정당하게 가진 것을 개인 연습용으로만 넣어 쓰세요.

## 개발
```bash
python3 tools/devserver.py 8765     # http://localhost:8765 (캐시 끔)
```
- 빌드 단계는 없습니다. 순수 HTML·CSS·JavaScript(ES 모듈)입니다.
- `tools/eval.html`은 대략 인식 정확도와 자동 넘김을 재는 로컬 전용 도구입니다. 정답 데이터, 악보, 시험 녹음은 저장소 밖에 둡니다.
  - `tools/make_perf.py` + `tools/render_perf.swift`: 정답 음으로 가상 연주를 만들어 맥 내장 피아노 음색으로 녹음 파일을 만듭니다.
- 주소에 `?debug`를 붙이면 자동 넘김 표시에 지금 위치(쪽·줄)와 확신이 나옵니다.
